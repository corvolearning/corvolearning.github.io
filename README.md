# Corvo Learning

Specialized learning and development partner for high growth companies, that delivers role-tailored, screen-free onboarding tracks powered by Libro.fm. This repo holds the source for the marketing landing page.

**Live site:** https://corvolearning.com 

## Editing
The site is a single static file — `index.html` — with all CSS and JS
inline. Edit it directly and push to `main`; GitHub Pages redeploys
automatically within a minute or two.
